# 雾下余粮（Tiny Signal V2.1.0）

一个以静默圣遗物为安全锚点、以远征探索为主要行为的 2D 格子回合制生存探索 Demo。

当前实现事实见 [`docs/design/current-game-status.md`](./docs/design/current-game-status.md)。

V2.0 技术边界见 [`docs/design/v2.0-persistent-world-mvp.md`](./docs/design/v2.0-persistent-world-mvp.md)。

V2.1 污染规则见 [`docs/design/v2.1-persistent-pollution.md`](./docs/design/v2.1-persistent-pollution.md)。

后续版本方向见 [`docs/design/v2-roadmap.md`](./docs/design/v2-roadmap.md)。

## 当前核心循环

```text
静默圣遗物 / 基地区域
→ 离开安全区
→ 探索持久世界
→ 发现地形、资源、怪物、巢穴和事件
→ 采集、绕行、战斗或继续深入
→ 根据生命、抗性、饥饿、背包和危险决定是否返回
→ 主动回到静默圣遗物
```

V2 保留“搜打撤”的风险决策，不再使用“庇护所 UI + 单次户外副本 + 撤离点”的空间结构。

## V2.1 已实现

- 主菜单开始或继续直接进入持久世界

- 世界中的静默圣遗物和安全起步区
- 圣遗物半径内停止移动饥饿消耗
- 屏蔽不高于保护阈值的地形污染
- 圣遗物管理、抗性恢复和逐块异变肉净化
- 树木、石矿、分回合采集、木材和石材库存
- 玩家位置、世界回合及资源变化状态持久化
- 20×20 跟随视口与三态战争迷雾
- 敌人方向视野、状态机、巢穴、战斗、尸体切割和随机事件
- 生命、疯狂、疯狂抗性和异变肉存档
- 战斗实际 HP 损失按损血者的位置形成格子级动态污染
- 动态污染永久写入世界存档，刷新或离开再返回后仍然存在
- 地图以低干扰的腐化色和痕迹分段反馈动态污染
- 桌面与移动端响应式操作
- 程序化音效、配置导入导出和旧地图编辑器

## 当前重要边界

- 世界没有撤离点；“3 次撤离 + 12 块肉”不再是 V2 当前目标。
- 旧庇护所 UI、撤离结算、Demo 目标和种植格代码仍保留用于兼容或历史工具，不属于 V2 正常主流程。
- `activeExpedition` 仍被复用为世界运行快照容器，保存怪物、尸体、迷雾、事件和 `sceneMadness` 等即时状态；格子级动态污染独立保存在 `WorldSave`。
- 饥饿尚未持久化；每次启动世界运行时仍按配置初始化。
- 战斗 HP 损失会 1:1 同时进入兼容统计 `sceneMadness` 与损血者所在格的永久动态污染；overkill 不产生额外污染。
- 怪物和巢穴目前复用旧固定布局，不是按区域生态生成。
- 木材和石材已经可采集，但尚无建设或制作用途。
- 动态污染目前不会扩散、衰减或改变生态；基地储物、种植、建筑、Chunk、污染生态和养殖尚未实现。

## 操作

- 移动：方向键或 WASD
- 交互：站在圣遗物、树木、石矿或尸体格按 E
- 接敌：尝试进入敌人所在格
- 战斗：方向键或 WASD 选择行动，回车或空格确认
- 道具：户外和战斗中可使用已获得的异变肉
- 手机：使用屏幕方向键和操作按钮

异变肉会恢复生命和饥饿，同时按该肉块剩余污染增加疯狂；食肉污染不被疯狂抗性抵消。玩家可以回到静默圣遗物净化异变肉或恢复抗性。

## 世界、迷雾与敌人

- 相同世界配置与 Seed 会复现相同地形、圣遗物、出生点、树木和石矿。
- 静态地形与基础污染由 Seed 重建；存档保存玩家位置、库存、资源状态及稀疏的格子级动态污染。
- 未探索区域为实体黑色遮罩；已探索区域保留低亮度记忆；当前可见区域正常显示。
- 普通敌人拥有四方向朝向和受障碍遮挡的扇形视野。
- 巢穴属于统一怪物配置，可按回合产生子怪；玩家主动进入巢穴格后进入普通战斗。

## 配置与旧地图编辑器

配置页仍保留 V1 关卡地图、撤离点和庇护所相关字段，用于旧存档、旧配置和地图草稿试玩兼容。V2 程序世界只复用其中部分成熟配置；旧地图编辑器目前不能直接编辑 100×100 程序世界。
